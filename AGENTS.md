# Project Instructions

## Frontend quality workflow

For frontend/UI/UX work, use the local `frontend-quality-orchestrator` skill.

Read:

- `docs/frontend/PRODUCT.md`
- `docs/frontend/DESIGN.md`
- `docs/frontend/FRONTEND_PLAYBOOK.md`

Preserve the project's established design language: warm clinical elegance, real imagery, cream/brown/taupe palette, oversized editorial typography, and restrained interactions.

Prefer existing HTML/CSS section patterns, assets, and tokens over creating new primitives.

For new UI:

Figma/context -> design direction -> implementation -> validation.

For polish:

Impeccable -> unslop-ui -> Web Design Guidelines -> validation.

For visual audits:

Audit first; do not redesign unless requested.

Explicit user requirements and the project's real design system override generic skill recommendations.
